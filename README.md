# Ahmed Amine Ouqlani — Engineering Portfolio

Personal portfolio of Ahmed Amine Ouqlani, first-year engineering student at ENSEEIHT (Toulouse INP), specializing in Electrical Engineering, Energy and Automatic Control (3EA).

Live site: https://amine-ouqlani.github.io

## Structure

- `index.html` — the whole site (About, Resume, Portfolio, Contact)
- `assets/css/style.css`, `assets/js/script.js` — styles and behaviour
- `assets/images/` — photos and project images
- `assets/docs/` — PDFs linked from the site (TIPE presentation, revision books, CV)
